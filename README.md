# Assignment Reminder Program

A small command-line Python program that tracks assignment due dates and reports upcoming, due-today, and overdue assignments.

## Open in VS Code

1. Clone or download this repository and open its folder in VS Code.
2. Install the Microsoft **Python** extension when prompted.
3. Open `assignment_reminder.py` and run it using **Run > Start Debugging** (or press **F5**) and choose **Run Assignment Reminder**.
4. Enter the number of assignments, each assignment name, and its due date in `MM/DD/YYYY` format.

The program uses only the Python standard library. No packages need to be installed.
